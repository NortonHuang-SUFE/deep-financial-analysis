# Valuation Summary

Summarize:

- Target company and valuation date.
- Current price, base implied price, upside/downside.
- Base WACC, terminal growth, terminal value as percent of EV.
- Main drivers from revenue growth, margin, WACC, and terminal assumptions.
- Data sources and `[UNSOURCED]` assumptions.
- Validation status and warnings.
