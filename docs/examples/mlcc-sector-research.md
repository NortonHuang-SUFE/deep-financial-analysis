# MLCC（多层片式陶瓷电容器）行业综合研究报告

> 生成时间：2026-06-10 | 数据截止：2026年5月

---

## 一、执行摘要

MLCC 行业正处于**量价齐升的超级上行周期**。三大核心驱动力叠加：① AI 服务器单机柜 MLCC 用量较传统服务器增长 8 倍（英伟达 Vera Rubin 单机柜价值 $4,320，较 GB300 增 182%）；② 新能源车单车用量 1.8 万只，是燃油车的 6 倍；③ 村田 2026 年 3 月宣布高端 MLCC 涨价 15%-35%，三星/国巨/风华跟涨。中国占全球产能 56%，但高端自给率不足 20%，**国产替代空间巨大**。A 股 MLCC 板块过去一年涨幅 64%-267%，当前估值偏高（PE 48-225x），需警惕周期性回调风险。

---

## 二、行业概览

### 2.1 产品定义与分类

MLCC（Multi-Layer Ceramic Capacitor）被称为"**电子工业食粮**"，是全球用量最大的被动元件。

| 分类维度 | 类型 | 说明 |
|---------|------|------|
| **介质材料** | C0G（NP0） | 温度稳定性最高，用于射频/振荡电路 |
| | X7R | 中等容值，温度特性好，最通用 |
| | X5R | 高容值，消费电子常用 |
| | X6S/X7S | 高温高容，AI 服务器/汽车专用 |
| **尺寸** | 01005（0.4×0.2mm） | 超微型，手机/IoT 用 |
| | 0201/0402 | 主流小型化尺寸 |
| | 0603/0805/1206 | 中大尺寸，汽车/工业用 |
| **应用领域** | 消费级 | 手机、PC、家电 |
| | 车规级（AEC-Q200） | 汽车 ADAS、BMS、OBC |
| | 工规级 | 基站、服务器、工业控制 |
| | 军规级 | 航空航天、军工通信 |

### 2.3 行业周期

MLCC 行业呈 ~4-5 年周期：

```
2017-2018  缺货涨价周期（供给收缩 + 需求爆发）
    ↓
2019-2020  下行去库存
    ↓
2021       第二轮缺货（疫情 + 宅经济）
    ↓
2022-2023  深度去库存（库存 4-5 个月，利用率降至 65%）
    ↓
2024       触底回升（库存正常化至 3-4 个月，利用率回升至 80%+）
    ↓
2025-2026  ★ 当前：上行周期加速（AI+汽车+涨价）
```

## 三、产业链/价值链

### 3.1 上游：原材料与设备

| 环节 | 关键材料 | 全球格局 | 中国本土代表 |
|------|---------|---------|-------------|
| 陶瓷粉体 | 纳米钛酸钡（BaTiO₃） | 日本堺化学/共立/富士钛垄断 | **国瓷材料**（300285）— 国内唯一打破日本垄断 |
| 电极材料 | 纳米镍粉 | 日本昭荣/东邦/住友 | **博迁新材**（605376）— 国内纳米镍粉龙头 |
| 载带/包装 | 纸质载带、离型膜 | 日本大王制纸 | **洁美科技**（002859）— 载带国内第一 |
| 生产设备 | 叠层机、烧结炉 | 日本/德国垄断 | 国产化率仍低 |

**上游投资逻辑**：国瓷材料是国内唯一具备 MLCC 介质粉体量产能力的企业，卡位不可替代；博迁新材 2025H1 净利润同比 +70%-101%，受 AI 服务器高容 MLCC 需求拉动。

## 六、行业风险与关键变量

### 6.1 主要风险

| 风险类型 | 具体描述 | 影响程度 |
|---------|---------|---------|
| **周期性回调** | MLCC 约 4-5 年一个周期，当前已处于上行中后段，板块 PE 50-225x 估值偏高 | ⚠️ 高 |
| **日韩技术壁垒** | 高端（车规/AI 服务器）MLCC 仍被日韩垄断，国产突破节奏不确定 | ⚠️ 高 |
| **低端产能过剩** | 消费级低端 MLCC 库存仍高于安全水位 30%，结构性分化持续 | ⚠️ 中 |
| **涨价可持续性** | 涨价部分受关税预期驱动的抢单效应，真实需求待验证 | ⚠️ 中 |
| **汇率波动** | 人民币升值削弱出口竞争力 | ⚠️ 低-中 |
| **军工订单不确定** | 鸿远/火炬等军品公司订单恢复时间不明 | ⚠️ 中（个别标的） |

## 七、投资策略建议

### 7.1 核心配置（长期持有）

- **三环集团（300408）**：MLCC 国产替代旗舰 + 材料一体化护城河，毛利率/ROE 同业最优，适合作为核心仓位
- **顺络电子（002138）**：PE 最低（48.7x）+ ROE 最高（15.2%），估值性价比最好的被动元件平台型公司

### 7.2 弹性配置（周期博弈）

- **风华高科（000636）**：国内产能最大，涨价周期中利润弹性最大（2024 扣非净利 +130%），但当前 PE 225x 已充分反映预期
- **博迁新材（605376）**：上游纳米镍粉龙头，营收 +64% 增长最快，AI 服务器高容 MLCC 直接受益

### 7.3 上游卡位

- **国瓷材料（300285）**：国内唯一 MLCC 介质粉体供应商，卡位价值确定性高，但增速偏慢（+6.3%）

### 7.4 观察/回避

- **鸿远电子/火炬电子**：军用 MLCC 为主，订单恢复时间不确定，短期回避
- **洁美科技**：增收不增利，PE 152x 估值偏贵

### 7.5 风险提示

> 板块过去一年涨幅巨大（64%-267%），短期追高风险较大。建议**回调买入**策略，关注涨价持续性和季度业绩验证。军工标的（鸿远/火炬）需等待订单拐点信号。
